# gta6-animated-shorts

A free [Claude Code](https://claude.com/claude-code) skill: **type a joke, get a ~35-second vertical cartoon short** in the format of the top GTA 6 cartoon shorts.

> "make a GTA 6 cartoon short: When your mom says one more mission"

Claude writes the beat sheet, builds the characters and the shot list, checks the timing against measured numbers, renders stills, checks them side by side, fixes what looks worse, then renders the video with sound effects on every beat.

Everything on screen is drawn with code (three.js): the room, the characters, the TV and the little game on it. Remotion encodes. No AI video, no image generation, no stock footage.

## What's inside

| | |
|---|---|
| `SKILL.md` | the step-by-step workflow Claude follows |
| `references/` | the measured format (length, cuts, camera, colour, sound levels), how to write the joke, how the characters are built and act, camera angles, colour and the night look, the sound cue sheet, the still-check method, and the Rockstar-safe rules |
| `template/` | the engine: a parametric character rig (builds, hair, outfits, signature props, 28 expressions, 9 hand shapes), 3D-projected flat sets with real 3/4, low and high angles, the TV/game screen, camera moves, a format checker, contact sheets, colour metrics, an audio mixer, a 48-sound synthesized effects kit + music bed, and 15 ElevenLabs effects we generated |
| `examples/one-more-mission/` | a complete short: the characters and the 28-shot list for "When your mom says one more mission" |
| `examples/little-brother/` | the skill's own test short: "When you finally get GTA 6 but your little brother wants a turn" (two kids, 27 shots), made start to finish using only this skill |

The format numbers come from measuring 19 animated GTA 6 shorts frame by frame (28,361 frames): 33–38 s, first shot under 1.1 s, a cut every ~1.3 s, one obstacle repeated 4–7 times, a rage peak at ~60%, the twist at ~92%, a 0.9–1.5 s button, thick warm-black outlines, muted colours with one saturated accent. No frames, clips or characters from those shorts are included: only the numbers.

## Install (one command)

```bash
git clone --depth 1 https://github.com/rendergoblin-112/gta6-animated-shorts.git ~/.claude/skills/gta6-animated-shorts
```

Restart Claude Code. The skill triggers on "make a GTA 6 cartoon short", "animated short", "turn this joke into a short"…

## Requirements

- **Node.js 18+**
- **ffmpeg** on your PATH (or set `FFMPEG=/path/to/ffmpeg`)
- About 1 GB of disk for `npm install` (Remotion downloads a headless Chrome on first render)
- *Optional:* an **ElevenLabs API key** to generate new sound effects and real voice sounds: `export ELEVENLABS_API_KEY=...`. Without it the synthesized kit is used (its voice sounds are crude placeholders).

## Example prompts

```
make a GTA 6 cartoon short: When you finally get GTA 6 but your little brother wants a turn
animated short: When the GTA 6 download says 1 minute left for 3 hours
turn this joke into a short like the mom one: When you try to play GTA 6 on your dad's laptop
```

## Doing it by hand

```bash
node ~/.claude/skills/gta6-animated-shorts/template/tools/new-short.mjs ./my-short
cd my-short && npm install && npm run sfx:synth
npm run check          # format numbers
npm run stills         # one still per shot -> out/stills
npm run render && npm run mix && npm run mux -- out/short.mp4
```

Edit `project/characters.js`, `project/shots.js` and `project/index.js` for a new joke. See `references/engine.md`.

## Rules this skill keeps

No GTA logo art, no "VI", no Pricedown-style font, no Rockstar characters, no in-game place names, no game footage or audio, nothing from other creators. Just the plain words "GTA 6" hand-lettered on a cartoon TV. Details: `references/rockstar-safe.md`. This is a fan comedy tool and is not affiliated with Rockstar Games or Take-Two Interactive.
