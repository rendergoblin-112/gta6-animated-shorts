# Writing the joke

A short in this format is one joke told with one repeated beat. The user gives you a line ("When you finally get GTA 6 but…"). Your job is to turn it into a beat sheet that hits the measured structure, then a shot list.

## The rules

1. **Title = the premise as a "When you…" line.** 7 of the top 10 titles start "When you / When I / Me when", including all top 5. Keep the user's wording if it already does.
2. **Want first, in the first second.** The hero is eager at the screen, already reacting, and "GTA 6" is readable on the screen by ~1 s.
3. **One obstacle, repeated 4–7 times (median 4).** Don't write four different jokes. Write one beat and play it again, worse each time. Each repeat is a character↔screen exchange.
4. **Escalate inside the repeat, not across topics.** Each loop is faster, closer, louder, angrier. The proven ladder: the obstacle gets **physically closer** each time (doorway → beside the couch → looming over the couch → full-frame face), **angrier** (stern → angry → furious → rage), and the loop gets **shorter** (e.g. 4.5 s → 3.9 s → 2.8 s → 2.0 s). The last repeat can be a quick half-beat that tips into the rage.
5. **Rage peak at 0.55–0.70 of the runtime**: a full-frame scream close-up on the fire card, with a camera shake. It can be the hero's rage or the obstacle's.
6. **Then a reversal of fortune**: the hero loses (collapse, snatch, time skip).
7. **Twist at ~92%**: the payoff undercuts the want (10/10 top shorts). The game is fake, delayed, unaffordable, sabotaged, already finished by someone else, or the person who stopped you is secretly doing the thing. The best twists re-use something already on screen (a prop changes hands, the obstacle turns out to be the culprit).
8. **Button: 0.9–1.5 s**, one big reaction (scream with shake, crushing the device, crying), then cut to black. No end card.
9. **No dialogue.** Wordless sounds are fine (gasp, whine, roar, cackle). All text lives on screens or clocks.
10. **The relatable frustration is the subject**: ads, installs, prices, delays, a parent, a sibling. 9/10 top shorts use a frustration with the game itself; family obstacles work when the twist turns them into a gamer.

## The beat sheet (fill this in before any shot list)

| # | Beat | Time (35 s short) | Your joke |
|---|---|---|---|
| 1 | Want: hero eager at the screen (pull-out) | 0–1.0 | |
| 2 | Premise on screen: "GTA 6" title / store / menu | 1.0–2.8 | |
| 3 | Gloat: evil grin + steepled fingers (push-in) | ~3–4 | |
| 4 | Progress: MISSION START / install bar, hero leans in | ~4–5.5 | |
| 5 | Obstacle #1 (slowest, farthest) + hero shock (bulging, bloodshot eyes) + consequence on screen | ~5.5–10 | |
| 6 | Obstacle #2 (closer, angrier) + reaction + consequence | ~10–16 | |
| 7 | Obstacle #3 (closest) + reaction + consequence | ~16–21 | |
| 8 | Obstacle #4 (quick half-beat) | ~21–22 | |
| 9 | **Rage peak** close-up, fire card, shake | ~21–23 (0.6) | |
| 10 | Fallout: blown back / snatch / collapse | ~23–26 | |
| 11 | Time skip or setup for the twist (clock insert, sneak back) | ~26–33 | |
| 12 | **Twist** reveal (pull-out on the reveal) | **~33 (0.92)** | |
| 13 | **Button** reaction, shake, hard end | last 1.3 | |

Rough loop shape: `[P: progress on screen] → [C/W: obstacle arrives] → [C: hero reaction] → [P: consequence on screen]`. That is 3–4 shots per loop, which gives the measured C↔P alternation automatically.

## Patterns that work for the twist

- **The obstacle is secretly the gamer** (the parent who says "bed" is playing at 3 AM).
- **The obstacle finished the thing** (the sibling who "just wanted a turn" completes 100% of the game).
- **The reward is fake** (stick-figure game, "COMING SOON", "$0.01", a meme).
- **The prop changes hands**: the hero's signature prop ends up on the antagonist. Free visual payoff, zero words.

## Worked example: "When your mom says one more mission" (examples/one-more-mission)

| Beat | What happens | Time |
|---|---|---|
| Want + premise | Kid bounces on the couch → TV "GTA 6" title → press → mission select | 0–2.8 |
| Gloat + progress | Evil grin, steepled fingers → MISSION START, he leans in | 2.8–5.7 |
| Obstacle ×4 | Mom stops him: dinner (doorway, walks in, stomps) → chores (beside the couch, broom) → bedtime (looming behind the couch, slipper) → he mashes START on a dead TV. Each time the TV goes off | 5.7–22.3 |
| Rage | Mom's wide-jaw scream on the fire card, fists pumping, shake | 22.3 (0.63) |
| Fallout | Kid blown back, almost falls off the couch; her sleeve snatches the controller | 23.5–25.9 |
| Setup | Clock 3:00 AM → kid peeks round the door → TV is on → he tiptoes ("dun dun DUN") | 25.9–33.4 |
| Twist | Mom is the one playing, wearing **his** green headphones; she raises one finger: "one more mission" | 33.37 (0.92) |
| Button | Kid's bloodshot scream, shake | last 1.3 s |

## Second worked example: "When you finally get GTA 6 but your little brother wants a turn" (examples/little-brother)

| Beat | What happens | Time |
|---|---|---|
| Want + premise + gloat | Big brother bounces → "GTA 6" title → evil grin → MISSION START | 0–5.4 |
| Obstacle ×4 (closer each time) | Little brother: toddles in to the end of the couch with puppy eyes → (a small arm pokes PAUSE) → right beside him tugging his arm (PAUSE again) → standing in front of the TV, arms out → his face in big brother's face, lip quivering | 5.4–20 |
| Rage | The little brother's tantrum on the fire card: eyes squeezed shut, tear streams, fists pumping | 20 (0.59) |
| Fallout | Big brother flops; the small hand snatches the controller; little brother's evil grin | 21–25 |
| Setup + fake success | 11:58 PM → still playing → he sweetly hands it back → big brother overjoyed → LOADING… (dun dun DUN) | 25–31.7 |
| Twist | GAME COMPLETE 100% | 31.7 (0.91) |
| Button | Big brother screams; the little brother asleep beside him | last 1.3 s |

A screen-text twist works but is weaker than a character reveal that needs no reading (the mom in his headphones). If the twist is on a screen, zoom into the screen, make the text huge and bright, and put a character payoff in the button.

## Failure modes seen while building

- **Too many ideas.** Four different interruptions that are different jokes read as a list. Same beat, escalated, reads as a joke.
- **The twist explained.** If the twist needs text to land, restage it so one frame shows it (who is holding what).
- **A slow middle.** If loops don't get shorter, the rage arrives late (check: `npm run check` → rage centre).
- **An outro.** Any end card or logo after the button kills the ending.
