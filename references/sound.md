# Sound: a cue on every beat

The short is wordless, so sound carries half the comedy. **Every action and every reaction gets a sound.** The example has 74 cues in 36 s (2 per second). The longest gap between effect onsets is 1.4 s.

## Mix rules (`npm run mix`)

- **Continuous bed** (sneaky pizzicato underscore, ~112 bpm) sitting **12 dB under the effects**. Effects are never quieter than the bed.
- **Room tone under everything** (code-generated brown noise), so there are no silent gaps: ≤ 5% of 33 ms windows below −45 dBFS (example: 0.00%).
- **Duck the bed** to 35% under the big moments (obstacle arrives, rage peak): `duck: [t0, t1]` on the shot.
- Bed drops to 60% for the night section: `bed: 'night'` (or `'twist'`, `'quiet'`) on those shots.
- **−14 LUFS integrated**, two-pass loudnorm, limiter at −0.9 dBFS (measured shorts: −16 to −9, median −14.6).
- Cues are written inside each shot, `sfx: [[t, 'name', dB], ...]` (t local to the shot, dB relative), so the sound follows every edit.

## Cue sheet: which sound on which beat

| Beat | Sounds (names in the kit) |
|---|---|
| Hook bounce / eager | `boing` on every bounce |
| Press start / menu | `click`, `zip`, `pop` |
| Evil grin | `kid_chuckle` |
| Mission start / progress | `mission_start`, `game_car`, `mash` (button mashing), `zip` on the lean-in |
| Obstacle arrives | `door_bang` + `record_scratch` (the music "stops"), `sting` (dramatic stab), `steps_angry`, `stomp`, a wordless grunt (`mom_hmm`) or a whine (`kid_whine`) |
| Hero shock | `eye_pop` + `kid_gasp`, `boing` on the landing, `gulp` after |
| Consequence on screen | `tv_off`, then `sad_trombone` (first time), `record_scratch` or `thump` later |
| Flop / fall | `slide_down` + `flump`, `scramble`, `bonk` at the end |
| Determination | `knuckles`, `zip` |
| Sneaking | `tiptoe`, `squeak_steps`, `door_creak` |
| **Rage peak** | `boom` + a wordless roar (`mom_roar`) or wail |
| Snatch | `yoink` + `zip`, `gulp` |
| Time skip | `night_amb` + `ticks` |

## Where sounds come from (lookup order)

1. `project/sfx/<name>.mp3|wav`: files for this short only (record or generate your own).
2. `sfx/eleven/<name>.mp3`: effects generated by us with ElevenLabs and shipped with the skill (15 so far: the five kid voices, record_scratch, sad_trombone, dun_dun, sting, boom, eye_pop, boing, slide_down, yoink, gulp). New ones you generate land here too.
3. `sfx/synth/<name>.mp3`: the **synthesized kit**, made from oscillators and noise by `npm run sfx:synth`. It works with no API key and is 100% original. The voice sounds in it (`kid_gasp`, `kid_wail`, `kid_chuckle`, `kid_whine`, `mom_hmm`, `mom_roar`, `mom_cackle`) are crude formant placeholders: replace them for a real upload.

`sfx/manifest.json` lists every name with the ElevenLabs prompt that makes our version.

**A new sound without an API key:** drop any file you made or recorded (your own, never a clip from elsewhere) at `project/sfx/<name>.mp3` and use `'<name>'` in the shot's `sfx`. `npm run mix` fails with a MISSING SOUNDS list if a name has no file anywhere.

## Making new effects

```bash
export ELEVENLABS_API_KEY=...                         # from your environment only; never write it in a file
npm run sfx:gen -- --missing --max 15                 # every name the shot list uses that has no ElevenLabs file yet
npm run sfx:gen -- --add kid_tantrum "Small child's wordless furious tantrum scream, cartoon, no words" 1.6
```

Every call is logged to `SOUND_LOG.md` (time, file, seconds, prompt, result). Set a budget with `--max`. If you already have your own ElevenLabs wrapper command, pass it with `--cmd /path/to/wrapper` (called as `wrapper "<prompt>" out.mp3 <seconds>`).

The mixer peak-normalises every file to −1 dBFS before applying the cue's dB, so a cue's level means the same whether the file came from the synth kit, ElevenLabs or your recorder (one generated boing peaked at −12 dB and vanished before this). `node tools/probe-sfx.mjs sfx/eleven` prints each file's length and levels: a check you can do without listening.

Prompt style that worked first time (no retries across 37 effects): **say what it is, how it moves, and "cartoon"; for voices add "wordless, no words"**. Example: "Cartoon eyes popping out: a quick rubbery pop followed by a springy wobble". Never ask for a meme sound, a named song, a game's audio or a famous clip.

## Honest limits

Nobody listened to these mixes during development: the checks are loudness, silence, cue timing and gap length. Listen before you post. If something is wrong by ear (a sting too long, a voice too loud), change its dB in the shot's `sfx` line and re-run `npm run mix && npm run mux`; no re-render needed.
